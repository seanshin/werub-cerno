# 검수 기록 양식 — 파일럿 질의당 3항목 (13_파일럿_운영계획.md §4)

> 위치 확정: 이 파일이 정본. 복사해 개인별로 기록하거나, 인쇄해 종이로 써도 된다.
> 질의당 1행. "오도" 또는 "안전 경고 누락" 발생 시 즉시 공유(§6 중단 기준 판단).

| 일시 | correlation_id | 유용성¹ | 근거 적절성² | 누락³ | 메모 |
|---|---|---|---|---|---|
| | | | | | |

1. **유용성**: `도움됨` / `무해` / `오도` — 답변이 판단에 준 영향
2. **근거 적절성**: `적절` / `부적절` — 인용이 주장을 실제로 지지하는가
3. **누락**: `없음` / `있음(내용 기재)` — 있어야 할 근거·경고가 빠졌는가

- `correlation_id` 는 답변 카드 하단에 표시된다 — 검수 접수(POST /review)와 대조 키.
- 포털 안 인라인 3문항(v0.1.3)을 쓴 경우 이 양식은 생략 가능. 양쪽에 다 기록하지 않는다
  (오도율 카운터 중복 방지 — 인라인 접수가 우선).
